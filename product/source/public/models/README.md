# Modele 3D wyposażenia

Pliki GLB używają metrów i osi Y skierowanej w górę. Każdy model ma własny lokalny początek układu współrzędnych; pozycje z pokoju nie są zapisane w pliku.

Wyposażenie biurka:

- `dell-alienware-aw3423dwf.glb`
- `palmer-monicon-xl.glb`
- `asus-proart-p16-h7606wr.glb`
- `elgato-stream-deck-xl.glb`
- `trust-gxt-144-rexx.glb`

Tylny rack:

- `riveco-rack-15u-equipped.glb` — stojak z MOTU 24Ai, Model D i Kobol Expander.
- `riveco-rack-15u.glb` — pusty stojak.
- `motu-24ai.glb`
- `behringer-model-d.glb`
- `behringer-kobol-expander.glb`

Modele można wygenerować ponownie poleceniem `npm run export:models` w katalogu `product/source`.
